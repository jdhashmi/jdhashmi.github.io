Feed Formulation Portal: backend APIs

  • Node.js
  • Express
  • MySQL
  • Clerk

Two trimesters as a backend developer at Gopher Industries, Deakin's capstone software company, building a portal that marine nutrition researchers use to design animal feeds.

  • A delete API that removes a feed and its ingredient links in one transaction, rolling back if anything fails
  • Clerk-authenticated endpoints returning each user's own data through parameterised SQL
  • Recycle-bin APIs with pagination, search across five fields, and whitelisted sorting to block SQL injection

Worked from backlog user stories through feature branches and reviewed pull requests in a team of 40+ contributors.
